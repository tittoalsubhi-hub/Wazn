# Database schema (Room v1, SQLCipher)

Spec entities → tables: RawSMS `raw_sms` (+ `sms_source` provenance), ApprovedSender `approved_sender` (+ `discovered_sender` header metadata, `bank`), Account `account` (+ `account_assignment` effective dates), Profile `profile`, FinancialCycle `financial_cycle` (manual openings; other cycles are derived), BankEvent `bank_event`, BudgetAllocation `budget_allocation` (settlements/allocation changes), CategoryLimit `category_limit` (+ `category`), TransferMatch `transfer_match` (+ `transfer_rejection`), SavingsGoal `savings_goal`, SavingsInstallment `savings_installment`, Forecast `forecast` (approved plans), RecurringObligation `recurring_obligation`, ObligationOccurrence `obligation_occurrence` (per-occurrence overrides; occurrences are generated deterministically), ObligationPaymentMatch `obligation_payment_match` (PK `eventId` → one movement pays one occurrence), UserAppearancePreference `appearance_pref`, AuditLog `audit_log`, plus `app_setting`, `alert_sent`.

Migrations: add every schema change as an explicit `Migration` in `BudgetDatabase.MIGRATIONS`, bump `version`, commit the exported JSON from `core/data/schemas/` (uploaded by CI as `room-schema`) and add a `MigrationTestHelper` test. Destructive migration is never enabled.
